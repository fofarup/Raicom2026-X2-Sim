# 从零安装

以下步骤以刚安装完成的 Ubuntu 22.04 LTS 为起点。每完成一步再继续下一步。

## 第 1 步：切换到 X11

### 目的

确保 Docker 内的 MuJoCo 可以显示图形窗口。

### 操作

注销当前 Ubuntu 账户。在登录界面选择用户后，点击右下角齿轮，选择
“Ubuntu on Xorg”，再登录。

执行：

```bash
echo "$XDG_SESSION_TYPE"
uname -m
```

### 预期输出

```text
x11
x86_64
```

### 失败排查

如果第一项为 `wayland`，重新注销并选择“Ubuntu on Xorg”。

### 完成确认

两行输出分别为 `x11` 和 `x86_64`。

## 第 2 步：安装 Git、Git LFS、tmux 和 Docker

### 目的

准备下载大文件、构建容器及管理多个终端。

先安装 Git 与 Git LFS：

```bash
sudo apt update
sudo apt install -y git git-lfs tmux ca-certificates curl x11-xserver-utils
git lfs install
```

按照 Docker 官方仓库安装：

```bash
sudo install -m 0755 -d /etc/apt/keyrings
sudo curl -fsSL https://download.docker.com/linux/ubuntu/gpg \
  -o /etc/apt/keyrings/docker.asc
sudo chmod a+r /etc/apt/keyrings/docker.asc
```

```bash
source /etc/os-release
sudo tee /etc/apt/sources.list.d/docker.sources >/dev/null <<EOF
Types: deb
URIs: https://download.docker.com/linux/ubuntu
Suites: ${UBUNTU_CODENAME:-$VERSION_CODENAME}
Components: stable
Architectures: $(dpkg --print-architecture)
Signed-By: /etc/apt/keyrings/docker.asc
EOF
```

```bash
sudo apt update
sudo apt install -y \
  docker-ce docker-ce-cli containerd.io docker-buildx-plugin docker-compose-plugin
sudo systemctl enable --now docker
sudo usermod -aG docker "$USER"
```

然后注销 Ubuntu 账户并重新登录。

也可以使用项目脚本完成同样操作：

```bash
./scripts/install_host_tools.sh
```

### 预期输出

重新登录后：

```bash
docker run --rm hello-world
git lfs version
tmux -V
```

`hello-world` 应打印成功消息，其余命令显示版本。

### 失败排查

若出现 Docker socket 权限错误，确认已经注销并重新登录。

### 完成确认

三个检查命令均成功。

## 第 3 步：克隆私有仓库

### 目的

把项目固定在约定目录。

### 操作

```bash
mkdir -p ~/x2_ws
cd ~/x2_ws
git clone git@github.com:fofarup/Raicom2026-X2-Sim.git x2_biao
cd ~/x2_ws/x2_biao
git lfs pull
```

如果尚未配置 SSH，可以使用 HTTPS：

```bash
git clone https://github.com/fofarup/Raicom2026-X2-Sim.git x2_biao
```

### 预期输出

```bash
ls -lh vendor/link_u_os_competition-main.tar.gz
```

文件约为 511 MB，而不是几百字节的 LFS 指针。

### 失败排查

私有仓库要求登录 GitHub。HTTPS 可使用 GitHub CLI：

```bash
gh auth login
gh auth setup-git
```

### 完成确认

大文件已完整下载。

## 第 4 步：检查宿主机

```bash
cd ~/x2_ws/x2_biao
chmod +x scripts/*.sh scripts/in_container/*.sh scripts/tmux/*.sh
./scripts/check_host.sh
```

### 预期输出

最后一行：

```text
宿主机检查全部通过。
```

## 第 5 步：初始化官方资源

### 目的

在 Linux 中原样解压，保留 Windows 无法正确创建的符号链接。

```bash
./scripts/bootstrap_assets.sh
```

### 预期输出

```text
官方资源初始化完成：.../x2_biao/.runtime/raicom2026
```

所有生成内容都位于：

```text
~/x2_ws/x2_biao/.runtime
```

## 第 6 步：构建 Docker 镜像

```bash
./scripts/build_image.sh
```

首次构建会下载 Ubuntu 22.04、ROS 2 Humble 和依赖，耗时取决于网络。

### 预期输出

```text
镜像构建完成：raicom2026-x2-sim:humble
```

检查：

```bash
docker image inspect raicom2026-x2-sim:humble >/dev/null && echo OK
```

## 第 7 步：启动容器并构建 AimDK 消息

```bash
./scripts/start_container.sh
```

```bash
docker exec -it raicom2026-x2-sim \
  bash -lc '/workspace/scripts/in_container/build_aimdk.sh'
```

### 预期输出

```text
aimdk_msgs 构建和接口检查通过。
```

编译产物统一位于：

```text
~/x2_ws/x2_biao/.runtime/ros/build
~/x2_ws/x2_biao/.runtime/ros/install
~/x2_ws/x2_biao/.runtime/ros/log
```

安装完成后继续阅读
[02-首次启动与控制.md](02-首次启动与控制.md)。
