# 首次启动与控制

运行前确保已经完成 [01-从零安装.md](01-从零安装.md)。

## 方案 A：手动多终端启动

### 终端 1：启动容器和 MuJoCo

```bash
cd ~/x2_ws/x2_biao
./scripts/start_container.sh
docker exec -it raicom2026-x2-sim \
  bash -lc '/workspace/scripts/in_container/start_sim.sh'
```

### 预期现象

出现 MuJoCo 图形窗口，场景中包含比赛地图和 X2 模型。

### 终端 2：启动 MC

```bash
cd ~/x2_ws/x2_biao
docker exec -it raicom2026-x2-sim \
  bash -lc '/workspace/scripts/in_container/start_mc.sh'
```

### 预期现象

终端显示：

```text
[SIM] Environment detected.
```

且没有立即退出。

### 终端 3：让机器人稳定站立

```bash
cd ~/x2_ws/x2_biao
docker exec -it raicom2026-x2-sim \
  bash -lc '/workspace/scripts/in_container/set_stand.sh'
```

出现 `Mode set successfully` 后，回到 MuJoCo 窗口点击 `Reset`。

机器人应恢复并保持稳定站立。

### 切换到运动模式

```bash
docker exec -it raicom2026-x2-sim \
  bash -lc '/workspace/scripts/in_container/set_locomotion.sh'
```

预期出现：

```text
Mode set successfully
```

### 执行低速前进并停止

```bash
docker exec -it raicom2026-x2-sim \
  bash -lc '/workspace/scripts/in_container/run_safe_demo.sh'
```

默认行为：

- 前进速度：`0.12 m/s`；
- 持续时间：`2 s`；
- 结束后连续 `1.5 s` 发送零速度；
- `Ctrl+C` 时同样发送停止指令。

预期日志：

```text
MC 输入源注册完成。
开始低速前进：0.12 m/s，持续 2.0 s
已连续发送零速度停止指令。
```

## 方案 B：tmux

```bash
cd ~/x2_ws/x2_biao
./scripts/tmux/start.sh
```

脚本启动 MuJoCo 和 MC，并打开控制终端。首次仍需按照顺序执行：

```bash
/workspace/scripts/in_container/set_stand.sh
```

点击 MuJoCo 的 `Reset`，然后：

```bash
/workspace/scripts/in_container/set_locomotion.sh
/workspace/scripts/in_container/run_safe_demo.sh
```

## 状态检查

在宿主机执行：

```bash
./scripts/status.sh
```

应看到 `aima-sim-app`、`mc_app_main` 和 ROS 2 节点。

## 停止

```bash
./scripts/stop_all.sh
```

脚本会先尽力发送零速度，再停止容器并撤销 X11 授权。
