# 睿抗2026 智慧养老组 — 国赛工程升级工作清单

> 依据：国赛规则修订稿 + 评分细则修订稿 + IK SDK + 地图包 + 夹爪模板

## 背景

国赛新规则将原有的 6 个任务合并为 3 个，全部为现场真机操作：
- **任务 1** (15分)：自主导航与交互就位（语音唤醒 → 导航到交互区-I）
- **任务 2** (35分)：基础交互（时间问答 + 数字颜色识别 + 表情切换 + 动作执行）
- **任务 3** (50分)：场景交互与自主服务（场景对话 → 导航到作业区 → 视觉抓取）
- **附加分** (50分)：全程自主雷达建图导航

核心要求：
- 禁止使用机器人自带语音大模型，须自行接入
- 机器人接收一次运行指令后全部自主完成
- 20分钟限时，最多2次运行
