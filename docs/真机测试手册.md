## 二、模式切换

机器人 MC 模式通过 SetMcAction 服务切换。先查看当前模式：

```bash
ros2 service call /aimdk_5Fmsgs/srv/GetMcAction aimdk_msgs/srv/GetMcAction "{}" 2>/dev/null | grep action_desc
```

### 常用模式

| 模式 | action_desc | 用途 |
|---|---|---|
| 站立 | `STAND_DEFAULT` | 就绪、等待 |
| 行走 | `LOCOMOTION_DEFAULT` | 导航移动 |
| 上身遥控 | `UPPERBODY_REMOTE_SPLIT` | 手臂/夹爪控制 |

### 切换命令

```bash
# 切到上身遥控模式（手臂+夹爪测试前必须切换）
ros2 service call /aimdk_5Fmsgs/srv/SetMcAction aimdk_msgs/srv/SetMcAction \
  "{header: {stamp: {sec: 0, nanosec: 0}}, source: rc, command: {action_desc: 'UPPERBODY_REMOTE_SPLIT'}}"

# 切回行走模式（导航前必须切换）
ros2 service call /aimdk_5Fmsgs/srv/SetMcAction aimdk_msgs/srv/SetMcAction \
  "{header: {stamp: {sec: 0, nanosec: 0}}, source: rc, command: {action_desc: 'LOCOMOTION_DEFAULT'}}"

# 切回站立模式
ros2 service call /aimdk_5Fmsgs/srv/SetMcAction aimdk_msgs/srv/SetMcAction \
  "{header: {stamp: {sec: 0, nanosec: 0}}, source: rc, command: {action_desc: 'STAND_DEFAULT'}}"
```

⚠️ **切换 US 模式前确保机器人站稳、周围无人。**

## 五、真机消息差异

真机 AimDK 版本与仿真 SDK 不同，以下字段需注意：

| 仿真 SDK | 真机 AimDK |
|---|---|
| `RequestHeader` | `CommonRequest` |
| `command_source = "rc"` | `source = "rc"` |
| `joint_cmds` (JointCommand列表) | `arm_pos` (float[14]) |
| `cmd.pos / vel / tor / kp / kd` | `cmd.position / velocity / effort / stiffness / damping` |
| `msg.header.seq += 1` | 不存在，删掉 |

## 六、常见问题

### Q: source 后 import aimdk_msgs 失败？
确认 AimDK 已编译：
```bash
ls ~/aimdk/install/setup.bash   # 应该存在
```

### Q: 手臂不动？
1. 确认已切到 US 模式
2. 确认话题正常：`ros2 topic list | grep upper_body`
3. 打印确认消息已发布：`ros2 topic echo /mc/upper_body_command -n 1`

### Q: 表情不显示？
确认 MC 已启动，PlayEmoji 服务在线：
```bash
ros2 service list | grep emoji
```
