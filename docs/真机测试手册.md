### 2.1 表情测试 (`test_expression.py`)

**功能**：逐个发送表情指令到 X2 面部屏幕，验证 PlayEmoji 服务。

**命令**：

```bash
# 自动遍历全部 8 种表情（快乐/悲伤/愤怒/睡觉/充电/疑惑/平静-卖萌/平静）
python3 test_expression.py --all

# 显示指定表情
python3 test_expression.py --emotion 快乐

# 交互模式（输入表情名→显示）
python3 test_expression.py
```

**预期结果**：X2 屏幕依次切换对应表情动画，每个持续 2 秒。

**故障排查**：
- `PlayEmoji 服务不可用` → MC 未启动或表情服务未加载，先启动 MC
- `表情设置失败` → 检查 ROS_DOMAIN_ID=26，确认跨板通信正常

### 2.2 手臂控制测试 (`test_arm.py`)

**功能**：控制双臂 14 个关节，验证预备姿态、5 种比赛手势、单关节调试。

**前提**：机器人处于 **US 模式**（`UPPERBODY_REMOTE_SPLIT`）。可通过 `competition_node.py` 的 `prepare()` 自动切换。

**命令**：

```bash
# 回到预备姿态（最安全的起始位置）
python3 test_arm.py --ready

# 执行指定手势
python3 test_arm.py --pose 挥左手
python3 test_arm.py --pose 右手敬礼
python3 test_arm.py --pose 双手打叉

# 单关节调试（参数：关节名 + 弧度值）
python3 test_arm.py --joint left_shoulder_pitch --angle -1.0

# 交互模式（命令：ready / pose <名> / joint <关节> <角度> / list / q）
python3 test_arm.py
```

**可用的手势名**：`预备` `挥左手` `挥右手` `左手敬礼` `右手敬礼` `双手打叉`

**可用的关节名**：
```
left_shoulder_pitch_joint   right_shoulder_pitch_joint
left_shoulder_roll_joint    right_shoulder_roll_joint
left_shoulder_yaw_joint     right_shoulder_yaw_joint
left_elbow_joint            right_elbow_joint
left_wrist_yaw_joint        right_wrist_yaw_joint
left_wrist_pitch_joint      right_wrist_pitch_joint
left_wrist_roll_joint       right_wrist_roll_joint
```

**安全注意**：
- 先运行 `--ready` 确保手臂在安全位置
- 单关节调试时角度不要超过 ±3.0 范围
- 手臂动作期间人不要站在机器人前方

**故障排查**：
- `手臂不动作` → 确认已切到 US 模式；检查 `/mc/upper_body_command` 话题有发布者
- `关节角度异常` → 检查角度是否在官方限位内（见 `core/gesture.py` 注释）

### 2.3 夹爪控制测试 (`test_gripper.py`)

**功能**：控制 OmniPicker 夹爪开合。

**命令**：

```bash
# 自动测试：双爪张开→闭合→张开
python3 test_gripper.py --test

# 指定操作
python3 test_gripper.py --left open      # 左爪张开
python3 test_gripper.py --left close     # 左爪闭合
python3 test_gripper.py --right open     # 右爪张开
python3 test_gripper.py --right half     # 右爪半开
python3 test_gripper.py --both close     # 双爪闭合

# 交互模式
python3 test_gripper.py
```

交互模式命令：`left open` | `right close` | `both half` | `test` | `q`

**位置值**：
- `open` = 1.0（完全张开）
- `close` = 0.0（完全闭合）
- `half` = 0.5（半开）

**注意**：仿真模型没有夹爪关节，本脚本仅真机有效。

### 2.4 麦克风测试 (`test_microphone.py`)

**功能**：检测可用录音设备 → 录音 → 波形分析 → 回放，验证麦克风硬件正常。

**命令**：

```bash
# 列出所有音频设备
python3 test_microphone.py --list

# 录 5 秒并回放（默认）
python3 test_microphone.py

# 指定录音时长（秒）
python3 test_microphone.py --duration 3
```

**预期流程**：
1. 打印 `arecord -l` 设备列表
2. 自动选择可用设备（按 `plughw:0,0` → `default` → `plughw:1,0` 尝试）
3. 录音 5 秒（终端显示 `🎤 录音 5 秒（请说话）...`）
4. 显示波形统计（peak/rms），判断信号强弱
5. 回放录音，验证听到自己声音

**检查项**：
- `rms > 100`：麦克风正常
- `rms < 100`：信号弱，检查麦克风连接、增益设置
- 回放听不到声音：检查扬声器/耳机连接

**X2 Jetson Orin NX 音频**：
- 内置音频：I2S 数字麦克风阵列（可能设备名为 `tegrasndt186ref`）
- USB 麦克风：插上后在 `arecord -l` 中显示为独立设备
- 如 `plughw:0,0` 失败，先用 `--list` 确认设备名

### 2.5 语音交互测试 (`test_voice.py`)

**功能**：完整 ASR 识别 + TTS 合成链路测试。

**命令**：

```bash
# 菜单模式
python3 test_voice.py

# 只测语音识别（ASR）
python3 test_voice.py --asr

# 只测语音合成（TTS），播放指定文本
python3 test_voice.py --tts "你好，我是X2"

# 只测语音合成，播放内置示例句
python3 test_voice.py --tts

# 循环对话模式：你说一句→识别→机器人复述
python3 test_voice.py --loop
```

**识别策略**（内置，无需选择）：
- 优先本地 SenseVoice（完全离线，CPU 推理）
- 讯飞云端备选（需网络，需配置 `config/asr_keys.json`）
- 失败自动回退键盘输入

**合成策略**：
- 优先 piper 离线 TTS（本地合成，零网络依赖）
- 备选 edge-tts 云端（音质更好，需网络）
- 无扬声器自动降级为日志（不报错）

**预期结果**：
- ASR 测试：说"你好"→ 终端打印识别结果
- TTS 测试：播放 4 句预设语句（机器人开口说话）
- 循环模式：对话回声（你说啥它复述啥）

## 四、常见问题

### Q: 手臂不动？
确认机器人处于 US 模式。运行 `competition_node.py` 的 prepare 流程会自动切换，或检查 MC 日志面板。

### Q: 语音识别不准？
1. 确认麦克风测试通过（`test_microphone.py`）
2. 环境噪音较大时靠近机器人说话
3. 外接 USB 麦克风可显著提升准确率
4. 比赛现场可连公共网络时，讯飞云端识别更准

### Q: TTS 不出声？
1. `test_voice.py --tts` 先验证 TTS 链路
2. 确认扬声器连接（X2 自带扬声器通常已连接）
3. 检查 piper 模型是否下载：`ls models/tts/zh_CN-huayan-medium.onnx`
4. 无扬声器时 TTS 自动降级为日志，不会报错

### Q: 夹爪不动？
确认机器人模型带 OmniPicker 夹爪。标准模型 `lx2501_3_t2d5` 不带夹爪，`lx2501_3_t2d5_raicom` 竞赛模型才带。

### Q: 设备名不对？
X2 真机的音频设备名可能与脚本内置列表不同。先跑：
```bash
arecord -l                # 看 capture 设备
python3 test_microphone.py --list  # 列出所有音频设备
```
记下实际的设备名（如 `plughw:CARD=tegrasndt186ref,DEV=0`），修改脚本中 `RECORD_DEVICES` 列表。
